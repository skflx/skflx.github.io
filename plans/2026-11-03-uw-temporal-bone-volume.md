# Spec: UW temporal bone volume, normal reference specimen (2026-11-03)

> Status lives in GitHub Issues (parent #225, one sub-issue per WP). This file holds the decisions,
> contracts and data. It changes only through PRs. Commits: one short line, no trailers.

## 0. Context

Owner, 2026-11-03: build an internal 3D reconstruction of the normal temporal bone CT in the UW
*Interactive Web-based CT Temporal Bone Module* (uwmsk.org/temporalbone). It is filed in the repo
as reference data for later recall of normal anatomy and for #225 (realistic OLSB). The facial
nerve, IAC and other surgically relevant structures are traced with care. No page reads it yet.

## 1. Decisions

| # | Decision |
|---|---|
| T1 | **Permission.** The owner's 2026-10-07 written permission from the UW atlas authors (recorded in `ssb/LICENSE-data.md`) covers this module too (owner, 2026-11-03). Credit the atlas and its institution; never name its authors in any file or commit. |
| T2 | **Inputs.** All four normal planes at the best resolution served: axial (61), coronal (21), parallel/Stenvers (23), perpendicular/Pöschl (17). Each slice exists as an unlabelled and a labelled 512 × 512 JPEG; that is the highest resolution UW serves (larger variants return 404). Raw downloads go in `tools/tbone-pipeline/incoming/` (gitignored) and are never committed. |
| T3 | **Frame = OLSB's** (`js/olsb/volume.js`): mm, a right ear, x lateral, y anterior, z superior, origin at the centre of the oval window, so #225 can register OLSB to it directly. |
| T4 | **Volume source = the axial stack.** The other three planes are registered to it and used to cross-check geometry and to add labelled landmarks. If a plane turns out to be a different specimen, it is used for labels only, and `registration.json` records that (the SSB coronal precedent). |
| T5 | **Scale is inferred**, as in SSB: the atlas is a screen capture of a bone-window display, not DICOM. The in-plane mm/px comes from the scout slice lines and anatomy cross-checks (cochlear basal turn, IAC, vestibule, ossicle sizes against standard values). Slice spacing comes from the scout map. Method and uncertainty are recorded. Values are 8-bit display levels, not HU. |
| T6 | **Reuse, not a fork.** Generic helpers from `tools/ssb-pipeline/uw/` (annotation mask, OCR, arrow tips, stacking) are imported or called, not copied, where they fit unchanged. New code goes only where the temporal bone differs. |
| T7 | **Generated data is never hand-edited**, as in SSB. Everything under `tbone/` is regenerated by the pipeline. |
| T8 | **Internal.** No page, test or CI job loads `tbone/`. It needs a README and a provenance file, and stays small. |

## 2. Outputs (`tbone/`, committed)

| File | What |
|---|---|
| `tbone/LICENSE-data.md` | provenance, permission, attribution line, derived-file table (SSB format) |
| `tbone/ct/ct.u8.gz`, `tbone/ct/ct.json` | axial display volume resampled isotropic in the T3 frame, cropped to the temporal bone; `ct.json`: dims, spacing, origin, frame, source slice map, scale method + uncertainty |
| `tbone/geometry/landmarks.json` | every UW label → a 3D point per arrow tip, in mm, with the source plane, slice and method, plus the `js/olsb/glossary.js` id where one fits (`g`, else null) |
| `tbone/geometry/sweeps.json` | centrelines (points in mm + radius) with per-point `detected` / `labelled` / `inferred`: facial nerve by segment (meatal/IAC, labyrinthine, geniculate, tympanic, second genu, mastoid, to the stylomastoid foramen), GSPN start, chorda if visible; IAC; cochlear and vestibular aqueducts; petrous ICA (vertical and horizontal); jugular bulb; sigmoid sinus; EAC; bony ET; the three canals; basal turn |
| `tbone/geometry/labels.json` + `tbone/ct/labels.u16.gz` (optional, WP T3) | air spaces and labyrinth segmented on the volume grid |
| `tbone/README.md` | how to regenerate, what each file means, limits |
